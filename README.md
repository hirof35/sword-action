Sword Action Gameシンプルな操作で敵をなぎ倒す、2Dトップダウン型アクションゲームです。スコアを稼ぎ、最深部に待ち受けるボスを撃破することが目的です。🛠 技術スタックLanguage: Python 3.xLibrary: PygameParadigm: オブジェクト指向プログラミング (OOP)Architecture: 状態遷移モデル（State Machine）によるシーン管理🎮 操作方法キーアクション矢印キー移動（上下左右）スペースキー剣を振る（移動方向へ攻撃） / シーン遷移🚀 ゲームサイクルタイトル画面: スペースキーでゲーム開始。通常モード: 徘徊する敵を倒してスコアを稼ぎます。ボスモード: スコアが1000点に達すると巨大なボスが出現します。リザルト: ボスを撃破すれば「CLEAR」、HPが尽きれば「GAME OVER」となります。✨ 主な設計の特徴動的攻撃システム: プレイヤーの向いている方向を計算し、その方向にのみ単一の攻撃判定（Rect）と回転させた画像を生成します。エフェクト管理: 敵撃破時に生成されるパーティクル（Effectクラス）は、寿命（タイマー）が尽きるとリストから自動削除されるメモリ効率の良い設計です。シーンマネジメント: SCENE_TITLE や SCENE_PLAY といった定数を用いて、単一のメインループ内でゲームの状態を管理しています。📂 セットアップPythonとPygameをインストールします。Bashpip install pygame
